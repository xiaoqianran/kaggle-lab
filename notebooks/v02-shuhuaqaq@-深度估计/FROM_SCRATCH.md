# Depth Estimation From Scratch

> 类似 **LLM from scratch**：一条可跑通的实验链，而不是概念清单。  
> 每一步固定五段：**概念 → 最小实现 → 真实输入 → 可观察输出 → 与上一步对比**。  
> 目标：用眼睛看到「这项技术到底修了什么病」。

配套：研究向蓝图见 [LEARNING_ROADMAP.md](./LEARNING_ROADMAP.md)；进度见 [PROGRESS.md](./PROGRESS.md)。

---

## 0. 全领域实验地图（一页总览）

```text
从零实现                    经典方法                 关键突破              现代系统              前沿
─────────────────────────────────────────────────────────────────────────────────────────────────
FS00 深度是什么/怎么错
FS01 针孔+反投影可视化
FS02 双目：相关匹配→视差
FS03 立体：半全局/代价体积直觉
FS04 监督：像素回归 MLP/小CNN     ← Eigen 思想
FS05 多尺度+SILog                 ← Eigen 2014 核心
FS06 U-Net 稠密头                 ← 现代 decoder 骨架
FS07 自监督：光度重投影             ← Zhou / Godard 起源
FS08 Monodepth2 三件套             ← min-reproj / automask / full-res
FS09 多数据集相对深度+对齐          ← MiDaS
FS10 ViT dense (DPT 头)           ← Ranftl 2021
FS11 伪标签基础模型                 ← Depth Anything 系
FS12 度量深度 / 焦距               ← Metric3D · UniDepth · Depth Pro
FS13 生成式深度（可选）             ← Marigold
FS14 研究闭环：协议·消融·假设       ← MDEC / 你的 H*
```

**主线一句话：**  
几何可观性 → 匹配求深度 → 学习替代匹配 → 无 GT 用光度 → 大规模相对基础模型 → 绝对尺度/边界/零样本。

**刻意不并入主线（旁支）：** 完整 NeRF/3DGS 训练栈、全景鱼眼专用、工业双目标定全流程（需要时再开）。

## 1. 步骤规格（每步五段）

下列每步的「最小实现」优先 **NumPy/PyTorch 短脚本**；「真实输入」优先 **可本地生成的纹理平面/公开小图/Kaggle 小数据集**，避免一上来被 100GB 数据集卡住。

图例：

| 标记 | 含义 |
|------|------|
| ✅ 已有代码 | 本仓库已实现可跑 |
| 🔜 下一步脚手架 | 目录/接口已预留 |
| 👁 必须看图 | 验收以可视化为主 |

---

### FS00 · 深度图是什么、指标如何骗人

| 段 | 内容 |
|----|------|
| **概念** | 深度 vs 视差 vs 逆深度；AbsRel / RMSE / SI-RMSE；对齐 |
| **最小实现** | `scripts/metrics.py` |
| **真实输入** | 合成 GT + 刻意错误的 pred（尺度、仿射、逆深度、噪声） |
| **可观察输出** | 表格：同一 pred 在 none/median/LS 下指标剧变 |
| **对比** | （起点）无 |
| **状态** | ✅ `run_p0_experiment.py` · `de-00` |
| **你应感知到** | 「刷榜数字」可以靠对齐协议改变；先统一协议再谈方法 |

---

### FS01 · 针孔相机：像素 ↔ 3D

| 段 | 内容 |
|----|------|
| **概念** | \(u=fX/Z+c_x\)；反投影射线；焦距如何缩放深度 |
| **最小实现** | `scripts/geometry.py`：project / backproject |
| **真实输入** | 已知平面 Z=const 的深度图 + 内参 |
| **可观察输出** | 点云三视图；改 fx 后点云「胀缩」 |
| **对比 FS00** | 从 2D 误差表 → 3D 几何后果 |
| **状态** | ✅ 核心函数+单测；可视化脚本见 `scripts/fs01_pointcloud_vis.py` |
| **你应感知到** | 深度错 20% = 点云整体缩放；不是「颜色有点不对」 |

---

### FS02 · 从零双目：块匹配视差

| 段 | 内容 |
|----|------|
| **概念** | 极线、视差 \(d\)、\(Z=fB/d\)；匹配代价（SAD/SSD） |
| **最小实现** | 纯 NumPy：左右图水平滑窗相关，输出 disparity |
| **真实输入** | 合成平移立体对（已知 B,f,Z）或 Middlebury 小样 |
| **可观察输出** | 左图 / 右图 / 视差热力图 / 反推深度 vs GT |
| **对比 FS01** | 深度不再「给定」，而从两张图 **算出来** |
| **状态** | ✅ `scripts/fs02_block_match_stereo.py` |
| **你应感知到** | 纹理弱→匹配崩；遮挡→条纹/空洞——这是后续学习要修的病 |

---

### FS03 · 代价体积直觉（经典立体的「结构」）

| 段 | 内容 |
|----|------|
| **概念** | 对每个像素枚举 d，得到 cost volume；赢家通吃 vs 平滑 |
| **最小实现** | 3D cost array + winner-take-all + 简单左右一致性检查 |
| **真实输入** | 同 FS02 立体对 |
| **可观察输出** | 某像素的 cost-vs-d 曲线；WTA 视差 vs 加平滑后视差 |
| **对比 FS02** | 从「滑窗」升级到「显式假设深度/视差」的搜索 |
| **状态** | ✅ `scripts/fs03_cost_volume.py` |
| **你应感知到** | 深度学习里的 cost volume / plane sweep 不是新物种，是这张表的可学习版 |

---

### FS04 · 从零学习：单像素/小窗口回归深度

| 段 | 内容 |
|----|------|
| **概念** | 把 MDE 当回归：\(d=f_\theta(I)\)；过拟合一张/一小集 |
| **最小实现** | 5 层 CNN 或 MLP-on-patch，L1 loss，无预训练 |
| **真实输入** | easy synthetic（颜色相关深度） |
| **可观察输出** | 训练曲线；pred 热力图从糊到成形 |
| **对比 FS02–03** | 不再搜索视差，**直接猜**；单目开始可能 |
| **状态** | ✅ 子集：`run_p2_train.py`（TinyUNet，偏 FS06）；极简版见 `scripts/fs04_tiny_regressor.py` |
| **你应感知到** | 单目能「猜对」只因数据有捷径（颜色=深度）；换纹理就崩——泛化危机 |

---

### FS05 · Eigen 关键：多尺度 + 尺度不变损失

| 段 | 内容 |
|----|------|
| **概念** | 粗到细；SILog；为何 log 空间对尺度稳 |
| **最小实现** | 两尺度头 + SILog vs L1 消融（固定数据） |
| **真实输入** | 同 synthetic；可选 NYU 子集 |
| **可观察输出** | 表：L1 vs SILog 的 AbsRel/SI-RMSE；多尺度边界是否更稳 |
| **对比 FS04** | 同样网络容量，损失/结构让「尺度类错误」更可控 |
| **状态** | ✅ 消融在 `run_p2_train.py`（silog vs l1）；笔记 `02-supervised-classic/NOTES.md` |
| **你应感知到** | 2014 的贡献是 **问题定义与损失**，不是 ResNet |

---

### FS06 · 稠密预测骨架：U-Net / skip

| 段 | 内容 |
|----|------|
| **概念** | 低层细节 + 高层语义；skip 救边界 |
| **最小实现** | TinyUNet（已有）vs 无 skip 的 encoder-decoder |
| **真实输入** | 多平面 synthetic（强边缘） |
| **可观察输出** | 边界 AbsRel；误差图画在物体轮廓上 |
| **对比 FS05** | 同损失下，结构决定边界 |
| **状态** | ✅ TinyUNet；消融可加 `scripts/fs06_skip_ablation.py`（见实现） |
| **你应感知到** | 深度图「糊」经常是 **分辨率通路** 问题，不是 loss 写错 |

---

### FS07 · 自监督起源：光度重投影

| 段 | 内容 |
|----|------|
| **概念** | 无深度 GT：用相邻帧/右图，warp 后比亮度 |
| **最小实现** | `photometric.py`：已知位姿 + 深度 → warp → L1/SSIM |
| **真实输入** | 几何正确的合成立体对 |
| **可观察输出** | 正确 Z vs 2Z 的 photometric error 差一个数量级 |
| **对比 FS04–06** | 监督信号从「GT 深度」换成「图像自己」 |
| **状态** | ✅ `run_p3_photometric.py` |
| **你应感知到** | 深度是 **解释两帧关系的隐变量**；错深度 = 错贴图 |

---

### FS08 · Monodepth2：让自监督真正能用

| 段 | 内容 |
|----|------|
| **概念** | min reprojection；automask；full-res multi-scale |
| **最小实现** | 读 `vendor/monodepth2` + 本地 mini min-reproj |
| **真实输入** | 合成动态区域（前景平移）或 KITTI 小序列（Kaggle） |
| **可观察输出** | 有/无 automask 的 ghosting；遮挡带误差 |
| **对比 FS07** | 同样光度，细节损失设计决定是否「能训」 |
| **状态** | ✅ 源码图 `papers/Monodepth2/SOURCE_MAP.md` + mini 实验 |
| **你应感知到** | SOTA 自监督论文的增量经常在 **训练技巧**，不在更深 backbone |

---

### FS09 · 相对深度工业化：多数据 + 对齐协议

| 段 | 内容 |
|----|------|
| **概念** | 数据集尺度不一致 → 预测相对/仿射不变量；评测要 LS 对齐 |
| **最小实现** | 伪相对表示（1/Z、log）+ 协议评测 |
| **真实输入** | 多场景 synthetic 混合尺度；可选 MiDaS 推理 |
| **可观察输出** | 同模型 none vs LS 的 AbsRel 断崖 |
| **对比 FS06** | 单数据集 metric 训练 → 跨数据集 relative |
| **状态** | ✅ `run_p4_foundation_protocol.py` |
| **你应感知到** | MiDaS/DA 的「强」首先是 **数据配方与协议**，其次才是 ViT |

---

### FS10 · DPT 时刻：Transformer 做稠密深度

| 段 | 内容 |
|----|------|
| **概念** | 全局感受野 → 大平面更一致； assembles tokens → 特征图 |
| **最小实现** | 推理：HuggingFace/DPT 或 torch hub；或最小 ViT-tiny + upsample 头 |
| **真实输入** | 室内外各 5 张真实照片（自己拍或网上） |
| **可观察输出** | CNN U-Net vs DPT/MiDaS 的平面平整度、远处结构 |
| **对比 FS09** | 同为 relative，结构变化带来的 **全局一致性** |
| **状态** | 🔜 协议已通；真实权重推理在 Kaggle/本机加 `fs10_dpt_infer.py` |
| **你应感知到** | 「墙不平」常常是局部 CNN 的病；ViT 修的是这个 |

### FS12 · 度量与零样本 SOTA 三叉戟

## 5. 验收：什么叫「这条 from-scratch 路线完成」

你能 **不看笔记** 演示：

1. 用双目块匹配从两张图算出深度，并指出弱纹理失败；  
2. 用小 U-Net 在 synthetic 上监督训出可用深度图；  
3. 展示光度 warp：错深度如何把图撕碎；  
4. 说明为何 relative 模型必须 LS 对齐；  
5. 用卷尺或已知尺寸场景解释 metric 与 relative 的产品差异；  
6. 对一篇 2024+ 论文做 5 分钟 claim 审查。
