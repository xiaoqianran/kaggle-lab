# 07-research-lab · P7 独立研究

**出口：** 审查新论文 claim；提出可证伪假设；阴性结果可复现。

## 工作流

1. 选当周 arXiv 检测论文 1 篇  
2. 用 `papers/TEMPLATE.md` 填 claim 表  
3. 标出「实验未支撑」的句子  
4. 设计最小可跑假设实验 `det-rNN-*`  
5. 写 `results/<exp_id>.json` + 解释

## Claim 审查清单

- [ ] 问题设定是否新？还是旧设定新模块？  
- [ ] 对比方法是否同年同设定？  
- [ ] 消融是否控制变量？  
- [ ] 主要涨点是否来自数据/尺度/训练更久？  
- [ ] 失败 case 是否展示？  

## 假设示例（可改）

- H1：小目标 AP_s 瓶颈在 stride，而非分类头容量  
- H2：匹配噪声主导 DETR 早期，增加 query 不如改 cost  
- H3：医学域上 mosaic 伤害小病灶多于帮助  

每个假设必须：预测 → 协议 → 结果 → 接受/拒绝。
